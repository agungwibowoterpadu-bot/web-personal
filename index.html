Panduan Setup Google Spreadsheet

Langkah 1: Buat Google Spreadsheet

  1. Buka https://sheets.google.com
  2. Klik Blank spreadsheet
  3. Beri nama: Database SDNMT 2027

Langkah 2: Buat Apps Script

  1. Di Spreadsheet, klik menu Extensions → Apps Script
  2. Hapus semua kode yang ada
  3. Klik tombol "Lihat Kode Apps Script" di bawah → Copy → Paste
  4. Klik Save (Ctrl+S) → beri nama Database SDNMT API

Langkah 3: Deploy sebagai Web App

  1. Klik Deploy → New deployment
  2. Pilih type: Web app
  3. Execute as: Me
  4. Who has access: Anyone
  5. Klik Deploy → izinkan akses
  6. Copy Web app URL (berakhiran /exec)

Langkah 4: Simpan & Kunci URL

  1. Paste URL di kolom atas
  2. Klik Test Koneksi untuk memastikan
  3. Klik "Simpan & Kunci" — URL akan terkunci otomatis
  4. Download file HTML terkonfigurasi untuk distribusi
